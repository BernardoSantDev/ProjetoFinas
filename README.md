
# Finans - Finanças Pessoais

O **Finans** é uma landing page moderna e responsiva desenvolvida para um serviço de controle financeiro. O projeto foca em uma interface limpa e intuitiva para apresentar soluções de gestão de contas, categorização de gastos e economia pessoal.

## 🚀 Tecnologias Utilizadas

O projeto foi construído com as melhores práticas de front-end:

* **HTML5**: Estruturação semântica.
* **CSS3**: Estilização personalizada e design de seções.
* **Bootstrap 4.6**: Framework utilizado para agilidade no desenvolvimento e total responsividade.
* **Font Awesome**: Ícones vetoriais para redes sociais e interface.

## 📋 Funcionalidades

* **Design Responsivo**: Layout que se adapta perfeitamente a computadores, tablets e smartphones.
* **Seção Hero**: Área de destaque com formulário de conversão e botões para apps.
* **Seções Informativas**: Demonstração de recursos como categorização de gastos e alertas de contas.
* **Grid de Benefícios**: Destaque para os diferenciais competitivos da plataforma.
